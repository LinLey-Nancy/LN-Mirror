# M0 实机验证清单（LN-Mirror 0.1.0）

方案里最关键、也最不能靠推理下结论的一项：**scrcpy 的画面窗口在你这台电脑的真实显卡驱动下，能不能被稳定地调成半透明，以及鼠标穿透是否真的生效**。这一份就是让你在实机上把它验完的记录表。

结论只接受两种形态：**通过（写下测到的现象）** 或 **不通过（写下具体表现）**。「看起来还行」不算结论，因为不同显卡驱动表现差别很大。

建议记录：手机型号与安卓版本、显卡型号、Windows 版本、驱动版本、每个渲染后端的实测表现。

---

## 一、基线：不加任何透明

1. 渲染后端保持 `auto`，不透明度 100%，关掉鼠标穿透，点「应用设置并重连」。
2. 连续滚动桌面、播放视频 2 分钟。

- [ ] 画面能出，且持续流畅，没有黑屏、闪烁或卡死
- [ ] 鼠标点击、长按拖动、滑动、滚轮、右键返回都正常
- [ ] 主窗口「引擎帧率」有数值且稳定

## 二、不透明度（每档都要肉眼确认，不要只看滑块数值）

在不透明度 100 / 75 / 50 / 25 / 1 / 0 之间来回拖动，每次等 1 秒。

- [ ] 100% 完全不透明，能清楚看到画面里的细节
- [ ] 50% 能同时看清手机画面和它下面的电脑内容
- [ ] 25%、1% 明显变淡，但**没有出现整块发白、纯黑、闪烁或马赛克**
- [ ] 0% 画面完全看不见，工具条和托盘**仍然可见可点**
- [ ] 从 0 拖回非 0，画面立刻恢复正常

**如果任一档位出现整块发白、纯黑、刷新异常或明显掉帧，先记下来，然后去第五步换渲染后端重测同一批操作。**

## 三、鼠标穿透（必须在别的程序窗口上试）

准备两个可点的目标：记事本，和一个浏览器窗口。把画面窗口拖到它们上面。

1. 关掉穿透，点画面：应该操作手机。
2. 打开穿透，点画面：应该点到下面的记事本 / 浏览器，而不是手机。
3. 回到主窗口点「验证鼠标穿透」，记下结论：
   - 结论是「穿透已生效」还是「穿透未生效」，把括号里的原文抄下来。
4. 半透明（比如 50%）状态下重复第 2 步：半透明和穿透要能同时存在。

- [ ] 穿透打开后，点击落到下方程序
- [ ] 穿透关闭后，点击回到手机
- [ ] 半透明 + 穿透可以同时存在，互不影响
- [ ] 工具条上的状态文字和实际行为一致

## 四、模式切换的手感（防止手机卡在拖动）

- [ ] 按住鼠标左键不松，同时点「穿透切换」：程序应等待你松手，3 秒内松开会正常切换；提示「鼠标仍处于按下状态」时没有强行切换
- [ ] 手机上正在长按时切到穿透：手机上不应出现「拖不动、一直按着」的状态
- [ ] 不透明度设为 0 时自动打开穿透；把不透明度调回 50% 后，穿透**保持**开启，需要你主动关掉才回到操控

## 五、渲染后端兼容性（透明无效时的主力排查）

如果第二步有问题，按顺序各试一遍，每试一次都要「应用设置并重连」：

| 渲染后端 | 不透明度 50% 是否生效 | 帧率影响 | 备注 |
|---|---|---|---|
| `auto`（默认） | | | |
| `software` | | | |
| `opengl` | | | |
| `direct3d` | | | |

- [ ] 至少有一个后端能在 50% 下稳定半透明且不掉帧
- [ ] 如果 `software` 能但 `auto` 不能，说明是显卡驱动与默认后端不兼容，把结论和表格一起记下来

## 六、拔插、休眠、多显示器

- [ ] 连接中拔掉数据线：画面立刻停止并提示，不残留不可见的反控窗口
- [ ] 拔掉后重新插入（手机已授权）：5 秒内重新出画
- [ ] 在手机上撤销 USB 授权：程序回到「等待手机授权」，不反复重启连接
- [ ] 把画面窗口拖到第二块显示器，然后拔掉该显示器：用工具条「找回画面」能把它拉回来
- [ ] 电脑休眠再唤醒：画面仍在，工具条仍可操作
- [ ] 直接点画面窗口的关闭（无边框模式下用 Alt+F4）：程序回到未连接状态，不崩

## 七、退出

- [ ] 托盘右键退出后，任务管理器里没有残留的 `scrcpy.exe` 进程
- [ ] 退出后手机屏幕恢复原状（不残留投屏状态）
