# M0 实机验证清单（LN-Mirror 0.1.0）

方案里最关键、也最不能靠推理下结论的一项：**scrcpy 的画面窗口在你这台电脑的真实显卡驱动下，能不能被稳定地调成半透明，以及鼠标穿透是否真的生效**。这一份就是让你在实机上把它验完的记录表。

结论只接受两种形态：**通过（写下测到的现象）** 或 **不通过（写下具体表现）**。「看起来还行」不算结论，因为不同显卡驱动表现差别很大。

建议记录：手机型号与安卓版本、显卡型号、Windows 版本、驱动版本、每个渲染后端的实测表现。

---

## 一、基线：不加任何透明

1. 渲染后端保持 `auto`，不透明度 100%，关掉鼠标穿透，点「应用设置并重连」。
2. 连续滚动桌面、播放视频 2 分钟。

- [ ] 画面能出，且持续流畅，没有黑屏、闪烁或卡死
- [ ] 鼠标点击、长按拖动、滑动、滚轮、右键返回都正常
- [ ] 主窗口「引擎帧率」有数值且稳定

## 二、不透明度（每档都要肉眼确认，不要只看滑块数值）

在不透明度 100 / 75 / 50 / 25 / 1 / 0 之间来回拖动，每次等 1 秒。

- [ ] 100% 完全不透明，能清楚看到画面里的细节
- [ ] 50% 能同时看清手机画面和它下面的电脑内容
- [ ] 25%、1% 明显变淡，但**没有出现整块发白、纯黑、闪烁或马赛克**
- [ ] 0% 画面完全看不见，工具条和托盘**仍然可见可点**
- [ ] 从 0 拖回非 0，画面立刻恢复正常

**如果任一档位出现整块发白、纯黑、刷新异常或明显掉帧，先记下来，然后去第五步换渲染后端重测同一批操作。**

## 三、鼠标穿透（必须在别的程序窗口上试）

准备两个可点的目标：记事本，和一个浏览器窗口。把画面窗口拖到它们上面。

1. 关掉穿透，点画面：应该操作手机。
2. 打开穿透，点画面：应该点到下面的记事本 / 浏览器，而不是手机。
3. 回到主窗口点「验证鼠标穿透」，记下结论：
   - 结论是「穿透已生效」还是「穿透未生效」，把括号里的原文抄下来。
4. 半透明（比如 50%）状态下重复第 2 步：半透明和穿透要能同时存在。

- [ ] 穿透打开后，点击落到下方程序
- [ ] 穿透关闭后，点击回到手机
- [ ] 半透明 + 穿透可以同时存在，互不影响
- [ ] 工具条上的状态文字和实际行为一致

## 四、模式切换的手感（防止手机卡在拖动）

- [ ] 按住鼠标左键不松，同时点「穿透切换」：程序应等待你松手，3 秒内松开会正常切换；提示「鼠标仍处于按下状态」时没有强行切换
- [ ] 手机上正在长按时切到穿透：手机上不应出现「拖不动、一直按着」的状态
- [ ] 不透明度设为 0：画面消失，且画面那块区域点不到（点击落到下面的窗口）；主窗口「鼠标穿透」复选框**不应该**被自动勾上
- [ ] 把不透明度从 0 调回 50：穿透保持你原来的状态（没勾就还是没勾），不会残留开启
- [ ] 反复把不透明度在 0 和 50 之间来回拖，鼠标穿透复选框始终不变

## 五、这次新增的交互

### 悬停显示画面

- [ ] 勾上「鼠标悬停显示画面」：画面立刻变透明，下面的窗口能正常点到
- [ ] 鼠标移进画面范围：画面按设定的不透明度出现；移开又变透明
- [ ] 鼠标在画面边缘来回移动时，画面不会一闪一闪地反复显隐
- [ ] 勾上后点「恢复 100」：悬停显示被关掉，画面保持可见，鼠标移开也不会消失

### 隐藏时的位置提示

- [ ] 「隐藏时的位置提示」三档都试一遍：不提示 / 淡边框 / 角标
- [ ] 选「淡边框」或「角标」时，画面隐藏后原来的位置能看到淡淡的标记，且标记不挡住下面的窗口点击

### 鼠标指针

- [ ] 鼠标停在画面上不动约 0.2 秒：系统箭头消失，出现一个小定位点
- [ ] 鼠标一动：箭头回来
- [ ] 鼠标移出画面：箭头保持正常，定位点消失
- [ ] 画面四周的把手不会一进来就出现（停一会儿才出现），想点画面最外圈时点得到手机

### 工具条

- [ ] 工具条紧贴画面上边缘，中间没有明显空隙；画面拖动时工具条跟着走
- [ ] 画面放到屏幕上边缘：工具条自动改贴画面下边缘
- [ ] 取消「工具条跟随画面」：拖工具条把手只移动工具条，画面留在原地；拖画面四周的把手只移动画面
- [ ] 取消跟随后关掉程序再开：工具条还在上次自己拖的位置
- [ ] 画面取消置顶时，工具条也不再浮在最上层

### 无边框与任务栏

- [ ] 勾选/取消「画面窗口无系统边框」：立刻能看到系统标题栏出现或消失，**不需要**重连
- [ ] 取消无边框后，拖动和缩放把手仍然可用，且对齐在画面边缘而不是标题栏上
- [ ] 任务栏里不再出现一个独立的投屏图标（画面窗口不再是独立任务项）

## 六、渲染后端兼容性（透明无效时的主力排查）

如果第二步有问题，按顺序各试一遍，每试一次都要「应用设置并重连」：

| 渲染后端 | 不透明度 50% 是否生效 | 帧率影响 | 备注 |
|---|---|---|---|
| `auto`（默认） | | | |
| `software` | | | |
| `opengl` | | | |
| `direct3d` | | | |

- [ ] 至少有一个后端能在 50% 下稳定半透明且不掉帧
- [ ] 如果 `software` 能但 `auto` 不能，说明是显卡驱动与默认后端不兼容，把结论和表格一起记下来

## 七、拔插、休眠、多显示器

- [ ] 连接中拔掉数据线：画面立刻停止并提示，不残留不可见的反控窗口
- [ ] 拔掉后重新插入（手机已授权）：5 秒内重新出画
- [ ] 在手机上撤销 USB 授权：程序回到「等待手机授权」，不反复重启连接
- [ ] 把画面窗口拖到第二块显示器，然后拔掉该显示器：用工具条「找回画面」能把它拉回来
- [ ] 电脑休眠再唤醒：画面仍在，工具条仍可操作
- [ ] 直接点画面窗口的关闭（无边框模式下用 Alt+F4）：程序回到未连接状态，不崩

## 八、退出

- [ ] 托盘右键退出后，任务管理器里没有残留的 `scrcpy.exe` 进程
- [ ] 退出后手机屏幕恢复原状（不残留投屏状态）
- [ ] **从托盘右键点「退出 LN-Mirror」：托盘图标消失后，进程管理器里应该立刻就没有 `LN-Mirror.exe` 了**（以前偶发"图标没了、进程还在"）
- [ ] 连着手机时从托盘退出：同样要进程立刻消失，最长不超过 10 秒（超过 10 秒会强制结束，并在日志里留下"退出超时"）
- [ ] 从托盘退出后再打开一次：能正常起来，不受上次退出的影响
- [ ] 主窗口点关闭只是收进托盘（进程还在），这跟"退出"不是一回事，别混
