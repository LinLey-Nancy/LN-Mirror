# LN-Mirror 使用说明（1.0.0）

把安卓手机画面半透明地挂在电脑桌面上，用鼠标直接操作手机。

当前版本支持 **USB 有线** 和 **局域网无线** 两种连接方式。声音转发还没有做。

---

## 一、运行前需要准备

| 项目 | 要求 |
|---|---|
| 电脑 | Windows 10 或 Windows 11，64 位 |
| 手机 | 安卓，开启了「开发者选项」和「USB 调试」；局域网连接另需安卓 11 及以上开启「无线调试」 |
| 连接 | USB：一根**能传数据**的 USB 线（有些线只能充电）；局域网：电脑与手机在同一网络 |
| 手机权限 | 不需要 Root |

手机端第一次使用要开两个开关：

1. 设置 → 关于手机 → 连点「版本号」7 次，进入开发者选项；
2. 开发者选项里打开「USB 调试」；
3. 用数据线连上电脑，手机弹出「允许 USB 调试吗」时勾选「始终允许使用这台计算机进行调试」，点确定。

少数机型（小米的「USB 调试（安全设置）」等）还需要额外打开一个开关，否则鼠标点不动手机。程序会提示，按手机上的提示处理即可。

## 二、开始使用（USB）

1. 双击 `LN-Mirror.exe`；
2. 主窗口左侧连接方式选「USB 有线」，「当前设备」里选中你的手机，点「连接」；
3. 画面出现在桌面上，上方会出现一条**独立工具条**。

主窗口关掉不会退出程序，它会缩到系统托盘（画面会继续投屏）；从托盘图标右键可以随时找回主窗口、工具条，或者直接恢复画面。

## 三、局域网（无线）连接

推荐环境：电脑有线接路由器，手机用稳定的 5 GHz / 6 GHz Wi-Fi。

### 第一次：配对（每部手机只需一次）

1. 手机上：开发者选项 → 打开「无线调试」→ 点进「无线调试」→ 选「使用配对码配对设备」，屏幕上会弹出**配对码**和**配对地址（IP:端口）**；
2. 主窗口左侧连接方式选「局域网」。正常情况下「发现的设备」里会自动出现一条「待配对」，点「去配对」会自动填好配对地址；
   没有自动出现的话，把手机上显示的配对地址手动填进「配对新设备」的地址框；
3. 输入手机上的 6 位配对码，点「配对并连接」。

配对码只用于这一次配对，程序不保存、不写日志。配对成功后这部手机会进入「历史设备」，以后不用重新配对。

### 以后：直接连接

- 「历史设备」里点「连接」即可；也可以从「发现的设备」里点「可连接」的设备，或手动输入手机「无线调试」主页显示的 IP:端口。
- 注意：手机「无线调试」主页的端口和配对端口**不是同一个**，手动输入时以主页显示为准。

### 断线与重连

- 默认开启「断线后自动重连」：画面因网络中断掉线后，程序会按 5 / 10 / 20 秒间隔自动重试 3 次；启动程序时也会自动重连上次用过的局域网设备并恢复画面。可在「局域网」页签里关掉。
- 手机的 IP 或端口变化了不要紧：历史设备会按配对时的身份自动寻找新的地址。

### 连不上时按这个顺序查

1. 手机「无线调试」是否还开着（锁屏久了有些机型会自动关）；
2. 电脑和手机是否在**同一个网段**（电脑连了 VPN、手机用了访客 Wi-Fi 都不算）；
3. 路由器是否开了「AP 隔离 / 客户端隔离」（开了就互相找不到，需要关掉）；
4. 电脑防火墙是否拦了 adb（第一次无线连接时如果弹过防火墙提示，选允许）；
5. 配对信息失效（手机换过网络或重开过无线调试）→ 重新配对一次。

### 旧机型备用入口

「备用：USB 已授权手机切无线」是给不支持配对码的旧系统用的：手机插着数据线且已授权，输入手机 IP 后点「切换并连接」。仅限可信局域网使用，用完建议在手机开发者选项里关掉无线调试。

## 四、移动与缩放画面窗口

画面窗口默认没有系统标题栏和边框。主窗口里的「画面窗口无系统边框」只管这一件事，**点一下立刻生效，不用重连**；不勾选就用系统自带边框，可以直接拖标题栏移动、拖边缘缩放。

**把鼠标停在画面上**，过一会儿四周会出现一圈半透明的把手：

- 按住**四条边**拖动 = 移动窗口；
- 按住**四个角**拖动 = 缩放窗口（自动按手机画面比例锁定，窗口边界始终贴合画面，不会出现黑边）；
- 把手只在鼠标停稳后出现，平时不挡画面；不透明度为 0% 或开启鼠标穿透时自动隐藏。

把手要停一会儿才出现，是为了让你想点手机的时候点得到画面最外圈那一圈，而不是一点就变成拖窗口。两种边框模式下把手都能用。

鼠标停在画面上不动约 0.15 秒后，系统箭头会隐藏，换成程序自己画的一个小定位点；鼠标一动箭头就回来，看画面时不会被箭头压住。

不需要把手可在主窗口关掉「悬停显示拖动把手」。

## 五、常用控制

### 不透明度（0–100%）

只有**画面窗口**会变透明，工具条和托盘始终看得见。滑块旁有 0 / 25 / 50 / 75 四个预设按钮，也可以直接输入数值。

- 100%：完全不透明，和普通投屏一样；
- 50% 左右：能同时看到画面和下面的电脑内容，最常用；
- 0%：画面完全看不见。

画面看不见时，它不会挡住下面的窗口（自动不接收点击），但**不会**改掉你勾选的「鼠标穿透」状态，把不透明度调回非 0 后穿透照旧。

程序记住你上次用的**非零**不透明度。重启或重新连接不会直接变成看不见，需要时点「恢复 100」。

### 鼠标悬停显示画面

主窗口勾上「鼠标悬停显示画面」后，画面常态是完全透明的，鼠标移到画面上才按不透明度滑块设定的值显示出来，移开又变回透明。

- 这时滑块表示"显示出来时有多浓"，主窗口里的标题会变成「悬停显示」，旁边写着当前是「隐藏中」还是「显示中」；
- 画面常态透明时，可以在「隐藏时的位置提示」里选不提示 / 淡边框 / 角标，用一个淡淡的标记告诉你画面原来在哪；
- 点「恢复 100」（工具条、托盘、快捷键都行）会顺手把这个模式关掉，否则鼠标一移开画面又没了；
- 和鼠标穿透互不干扰：穿透开着的时候，画面显示出来也点不到手机；
- 画面不置顶时多半被别的窗口挡着，悬停显示和定位点都不会出现，先把「画面置顶」打开。

### 鼠标穿透

打开后，画面还显示着，但鼠标点击会**穿过**画面，落到下面的电脑应用上；关掉后点击又回到操作手机。

- 「看得见多少」和「点击去哪里」是两项独立设置，互不影响；
- 切换时会先确认你的鼠标按钮已经松开，避免手机端卡在拖动或长按状态；
- 状态会写在工具条和主窗口里，不会让你猜。

## 六、工具条

工具条是浮在画面旁边的一条独立小窗，和主窗口互不影响：

- 主窗口点「显示工具条」能把它叫出来，工具条上点「收起」把它收走，两个入口都在；
- 勾选「工具条跟随画面」时，工具条紧贴画面边缘，画面移动它跟着移动，拖工具条右边的把手是整体一起挪；画面顶到屏幕上边缘时，工具条自动改贴画面下边缘；
- 不勾选时工具条和画面各走各的：拖工具条的把手只移动工具条，画面用画面四周的把手单独拖；工具条的位置会记住，下次启动还在原处；
- 工具条的置顶跟着画面走：画面不置顶时，工具条也不浮在最上层。

## 七、找不到画面时

有四个互相独立的入口，任何时候都能用：

| 入口 | 用法 |
|---|---|
| 工具条 | 点「恢复 100」 |
| 主窗口 | 点「恢复 100」 |
| 托盘 | 右键托盘图标 →「恢复 100（取消穿透并找回画面）」 |
| 快捷键 | 默认 `Ctrl+Alt+Shift+R`；`Ctrl+Alt+Shift+T` 是穿透切换 |

快捷键可以在主窗口里改。如果被别的程序占用，主窗口会提示，这时用工具条和托盘即可。

「恢复 100」会同时把「鼠标悬停显示画面」关掉，免得画面刚恢复又被鼠标移开变透明。

画面窗口如果被拖到看不见的显示器上，主窗口点「环境自检」旁边的提示，或用工具条的「找回画面」按钮，都会把它移回当前显示器。

## 八、画质与流畅度

主窗口「画面与交互」里有三档，修改后在连接状态下点「应用设置并重连」生效：

| 档位 | 分辨率上限 | 帧率上限 | 码率 |
|---|---|---|---|
| 流畅 | 1280 | 60 | 4 Mbps |
| 均衡（默认） | 1920 | 60 | 8 Mbps |
| 清晰 | 1920 | 60 | 12 Mbps |

无线环境不稳定时建议先切「流畅」档。主窗口显示的「引擎帧率」来自 scrcpy 的解码统计，它不等于屏幕实际显示出来的帧率，也不能当成端到端延迟。程序不会显示没法真实测量的延迟数字。

**如果画面是全黑、或者设了不透明度却完全没变化**，说明当前显卡驱动和这个渲染后端不兼容。在主窗口把「渲染后端」从 `auto` 改成 `software`（或 `opengl`），点「应用设置并重连」再试。这是已知需要按机器实测的一项。

## 九、出问题了怎么查

1. 主窗口点「环境自检」：会逐项检查内置引擎、adb、配置目录和透明调用链，并把报告写进日志；
2. 主窗口点「复制诊断信息」：把完整状态复制到剪贴板，发给我即可，里面不含画面、输入内容、剪贴板内容和配对码；
3. 主窗口点「打开日志目录」，或直接看：

   ```
   %AppData%\LN-Mirror\logs\LN-Mirror-年月日.log
   ```

   配置在同目录的 `%AppData%\LN-Mirror\settings.json`。

常见情况：

| 现象 | 处理 |
|---|---|
| 未发现设备 | USB：换一根数据线，确认手机选了「文件传输/MTP」模式；局域网：确认无线调试已开、同一网段、路由器无客户端隔离 |
| 一直显示等待授权 | 手机上可能还有旧授权没清；拔插一次数据线，在手机上确认授权框 |
| 配对失败 | 配对码错或配对对话框已关闭（配对码随即失效），重新打开配对对话框再来一次 |
| 局域网连接被拒绝 | 端口填错：用「无线调试」主页的端口，不是配对端口 |
| 局域网连接超时 | 网段不通 / 客户端隔离 / 防火墙拦截，按第三节的排查顺序处理 |
| 点不动手机 | 该机型需要额外打开「USB 调试（安全设置）」，按手机提示处理 |
| 画面不透明 / 全黑 | 换「渲染后端」为 software 或 opengl 后重连；还不行就是显卡驱动与该组合不兼容，需要换方案 |
| 鼠标穿透自己被勾上了 | 现在不会了。画面为 0% 时只是自动不接收点击，不会改你勾的穿透状态；如果确实被勾上了，多半是点到了工具条上的穿透开关 |
| 画面看不见也点不到下面的程序 | 画面隐藏时不接收点击是正常的；把鼠标移开就会让开，或点「恢复 100」 |
| 拔了线画面不消失 | 拔线后程序会自动停止画面并提示；如果没有，点工具条「恢复 100」或从托盘断开 |

## 十、这个版本没有的功能

- 声音转发（只有画面和鼠标操作）
- 录屏、多设备并排、中文输入增强

退出程序时，会连同它自己启动的投屏窗口一起结束，不会留下看不见但还能操作的画面窗口。从托盘退出后，托盘图标消失的同时程序进程也应当消失（最长不超过 10 秒；万一清理卡住，程序会自己强制结束并在日志里留下"退出超时"记录）。
